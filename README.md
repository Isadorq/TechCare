# TechCare

![TechCare](https://tech-care-gules.vercel.app/index.html)

**TechCare** é um projeto desenvolvido como parte de um curso, criado para apresentar um produto da turma chamado **Neurobloom**. O **Neurobloom** é uma pulseira inteligente que monitora diversos dados de crianças com Transtorno do Espectro Autista (TEA), com foco em melhorar o acompanhamento e cuidado dessas crianças.

## 🔗 Link do Projeto

Você pode acessar o projeto online aqui: [TechCare](https://tech-care-gules.vercel.app/index.html)

## 💻 Tecnologias Utilizadas

- HTML
- CSS (se tiver usado, se não, pode remover)
- JavaScript (se tiver usado, se não, pode remover)

> Nota: O projeto foi desenvolvido de forma simples, usando apenas HTML para fins educativos.

## 🎯 Objetivo

O principal objetivo do **TechCare** é:

- Mostrar o produto **Neurobloom**, sua funcionalidade e design;
- Servir como apresentação prática do trabalho da turma.
